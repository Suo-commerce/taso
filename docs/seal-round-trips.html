What a Seal costs: the block log against ZFS, one TurnEnd

Measured on taso-test (VM, disk round trip ≈ 5 ms), P=1, 2026-10-26: block log Seal 37.7 ms (freeze 37.0, log 0.9, thaw 1.7), ZFS Seal 17.7 ms. The difference is not the Warden's work but where the dirty data's barriers run: through the ublk device and the Warden's own block-log process, each a user/kernel crossing and a disk round trip, against ZFS's transaction group inside one kernel.

Between Seals neither side does anything: the agent writes into ext4's page cache on both, and the Warden is idle. Fewer barriers per Seal (ext4's journal mode for Vessels, or a Seal that drains the device without a filesystem freeze) is the lever if the P=64 row on taso-p5 asks for one.
